
# Tutor Virtual ESUCAR (EduNora)

## Descripción del proyecto

EduNora es una aplicación Android desarrollada para funcionar como tutor virtual de apoyo académico para estudiantes de la Escuela de Suboficiales de Carabineros (ESUCAR).

El proyecto se desarrolla de forma colaborativa utilizando Android Studio, Kotlin, GitHub y Trello.

## Objetivo

Desarrollar una aplicación móvil que permita apoyar el aprendizaje de los estudiantes mediante herramientas digitales y funcionalidades de tutoría virtual.

## Tecnologías

- Android Studio
- Kotlin
- Gradle
- Git y GitHub
- Trello para planificación de tareas

## Organización de ramas

| Rama | Descripción |
|------|-------------|
| production | Versión estable y entregable |
| certification | Validación y pruebas |
| development | Integración del trabajo del equipo |
| feat/* | Desarrollo individual de funcionalidades |

## Flujo de trabajo

1. Crear una rama feat/* desde development.
2. Implementar la funcionalidad asignada.
3. Realizar commits descriptivos.
4. Subir la rama a GitHub.
5. Crear un Pull Request hacia development.
6. Revisar e integrar los cambios.
7. Promover los cambios a certification para pruebas.
8. Integrar en production la versión aprobada.

2. Abrir la carpeta del proyecto en Android Studio.

5. Ejecutar la aplicación.
